# Коллекция лендингов

Репозиторий с готовыми одностраничными сайтами на разные темы. Каждый лендинг лежит в своей папке, написан на чистых HTML, CSS и JavaScript, без фреймворков и сборщиков. Откройте `index.html` в браузере, и страница работает.

Лендинги можно взять за основу для своего проекта, показать клиенту как пример или использовать как учебный материал по вёрстке.

## Что внутри

| Папка | Тематика | Блоки |
|---|---|---|
| [`stroitelstvo/`](./stroitelstvo) | Таргетированная реклама | Оффер, этапы работы, результаты в цифрах, тарифы, консультация |

Новые лендинги добавляются по той же схеме: одна тема, одна папка.

## Структура репозитория

```
.
├── README.md
├── stroitelstvo/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── <новая-тема>/
    ├── index.html
    ├── style.css
    └── script.js
```

## Как запустить

Вариант 1. Откройте нужный `index.html` двойным кликом.

Вариант 2. Запустите локальный сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

После этого лендинги доступны по адресу `http://localhost:8000/<папка>/`.

## Принципы, общие для всех лендингов

- **Mobile-first.** Стили пишутся для телефона, на планшете и десктопе страница расширяется через `min-width`.
- **Без зависимостей.** Нет библиотек, внешних шрифтов и сборки. Страница загружается быстро и работает офлайн.
- **Пять блоков.** Оффер, суть предложения (этапы, преимущества или услуги), доказательства (цифры, кейсы), цены, форма заявки.
- **Единая система стилей.** Цвета, радиусы и тайминги анимаций вынесены в CSS-переменные в начале `style.css`.
- **Доступность.** Видимый фокус для клавиатуры, достаточный контраст, отключение анимаций при `prefers-reduced-motion`.
- **Один акцент.** В каждом лендинге одна заметная анимация или визуальный приём, остальное остаётся спокойным.

## Как добавить новый лендинг

1. Создайте папку с названием темы, например `fitness/`.
2. Скопируйте в неё `index.html`, `style.css` и `script.js` из любого существующего лендинга.
3. Замените палитру в `:root` в начале `style.css`.
4. Перепишите тексты в `index.html`: заголовок, подзаголовок, шаги, цифры, тарифы.
5. Замените визуальный акцент в первом экране на образ из вашей темы.
6. Добавьте строку в таблицу «Что внутри» в этом файле.

## Что заменить перед публикацией

- Цифры, цены и названия компаний в примерах вымышленные. Подставьте реальные данные.
- Форма заявки в `script.js` только проверяет поля и показывает подтверждение. Подключите отправку в CRM, Telegram-бота или на почту.
- Обновите `<title>` и `<meta name="description">` под ваш бизнес.
- Добавьте политику конфиденциальности, если собираете персональные данные.
